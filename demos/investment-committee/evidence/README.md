demo. Asteria, its policies, the case, and the supplied evidence are fictional;
the HM Treasury Green Book is a separately attributed public method source.

Published screenshots are reviewed to contain no personal data, customer data,
tenant identifiers, credentials, or private run identifiers. Microsoft product
UI and names may appear for compatibility evidence. Microsoft and other product
marks, UI, icons, fonts, and trade dress remain the property of their respective
owners; their appearance does not imply endorsement.

Recorded model outputs may be incomplete or wrong and are not investment,
financial, legal, engineering, or approval decisions. Run IDs and full host logs
remain private local audit material and must not be committed or published.

Before publication, a human reviewer must check redaction, synthetic scope,
source attribution, output accuracy, screenshot framing, and whether provider or
source terms permit the intended use. Repository MIT terms cover authored
annotations and metadata in this folder only; third-party UI and marks retain
their owners' rights. See the root `THIRD_PARTY_NOTICES.md` and
`docs/RESPONSIBLE-USE.md`.
## Package name history

The Cowork screenshots and `metadata/cowork-runs.json` in this folder were
captured while the uploaded package still used the earlier skill name
(`investment-committee-copilot`). The shipped skill now uses the canonical catalog slug, so a
freshly built package will not match the historical package hash recorded here.
The recorded hash is kept as provenance for the runs that were actually
executed, not as a checksum for the current download.
